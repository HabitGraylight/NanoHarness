# NanoLoop Project Instructions

- NanoLoop is an application-layer example above the NanoHarness kernel.
- One loop iteration creates one fresh NanoEngine.
- Verification evidence, not an agent completion claim, controls success.
- Every loop is bounded by iteration, time, and consecutive-failure budgets.
- Irreversible actions remain behind explicit human gates.
- Worker file tools must stay inside the selected workspace and must not expose `.git`.
